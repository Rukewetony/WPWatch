Frequently asked questions

Do I need to create an account on the WPWatch website?

No. Your WPWatch account is created and managed directly inside the WordPress plugin.

Where is my monitoring data stored?

Your monitoring and report data is stored in this WordPress installation. Subscription status is verified separately through the WPWatch subscription system.

What is the difference between Pro and Pro Multi-site?

Pro costs $5/month and allows up to 3 websites. Pro Multi-site costs $25/month and allows up to 7 websites.

How often does WPWatch check my website?

Free monitoring checks run hourly. Pro-level monitoring runs every 5 minutes.

Does WPWatch store visitor IP addresses?

Not in the current plugin version. Traffic is stored as daily page views and approximate unique visitors using a first-party random visitor cookie. IP address, browser, device and country details are not currently stored.

Can I export my reports?

Pro-level reporting supports PDF and CSV/spreadsheet exports, as well as report emails.

Can I cancel Pro?

Yes. Subscription changes are handled through the WPWatch subscription system.

Do I need a developer to use WPWatch?

No. WPWatch is designed for WordPress website owners who aren't developers. It shows the information in plain language so you can decide what needs attention.
